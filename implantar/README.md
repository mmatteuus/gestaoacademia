# Implantar — Dossiê do Frontend

## Objetivo

Este diretório contém o dossiê operacional para concluir, organizar e preparar o frontend do repositório `gestaoacademia` para entrada futura em um monorepo, preservando o que já existe e preparando a aplicação para receber backend depois.

## Trilha

**AUDITAR E MELHORAR**

## Escopo

Somente frontend.

## Regras de execução

1. O executor deve seguir exatamente a ordem dos arquivos.
2. O executor não deve abrir decisões novas fora deste dossiê.
3. O comportamento atual deve ser preservado sempre que não conflitar com correção obrigatória.
4. O responsável deve continuar opcional no cadastro de aluno.
5. Aluno e responsável devem ter contato explícito no frontend.
6. O frontend deve ficar organizado para encaixe posterior em monorepo.
7. Toda página deve manter o rodapé com `Desenvolvido por MtsFerreira` apontando para `https://mtsferreira.dev`.

1. `01-diagnostico.md`
2. `02-objetivo-final.md`

7. `07-checklist-validacao.md`

## Resultado esperado

Ao final da execução, o frontend deve:

- possuir rotas principais acessíveis;
- ter módulo de responsáveis plenamente integrado;
- concluir os formulários prioritários;
- desacoplar UI de mocks brutos;
- estar organizado para futura migração para `apps/web`;
- estar pronto para receber backend sem retrabalho estrutural grande.

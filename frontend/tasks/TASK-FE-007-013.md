# TASK-FE-007: Implementar Lazy Loading de Rotas

## Contexto

Todas as rotas são importadas diretamente, aumentando o bundle inicial.

## Inspiração

- React.lazy + Suspense

## Entregáveis

1. **App.tsx refatorado**:
   ```typescript
   const DashboardPage = React.lazy(() => import('./pages/DashboardPage'));
   const AlunosPage = React.lazy(() => import('./pages/AlunosPage'));
   // ... demais páginas
   
   // Wrapped in Suspense
   <Suspense fallback={<PageSkeleton />}>
     <Routes>...</Routes>
   </Suspense>
   ```

2. **PageSkeleton universal**

## Critérios de Aceite

- [ ] Bundle split funcionando
- [ ] Suspense fallback exibido durante load
- [ ] `npm run build` passa

## Dependências

- TASK-FE-004 (imports migrados)

## Comandos de Validação

```bash
npm run build
# Verificar chunks gerados
```
